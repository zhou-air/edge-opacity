Edge 透明度 1.0

使用方法
1. 打开 Edge，再双击 EdgeOpacity.exe。
2. 在下拉框中选择需要调整的 Edge 窗口。
3. 拖动“不透明度”滑块，范围为 5%～100%，按 1% 调整。
4. 点击快捷挡位可设为 100%、80%、60%、40%、20%、5%。
5. “恢复当前窗口”恢复选中窗口调整前的状态；“恢复全部窗口”恢复本次所有调整。

恢复快捷键
Ctrl + Alt + 数字键 0（主键盘）恢复本次调整过的全部窗口。
如果快捷键被其他程序占用，界面会提示，请改用恢复按钮。

行为说明
- 只列出 Edge 的独立窗口，包含最小化窗口；窗口列表每 3 秒自动刷新，也可手动刷新。
- 透明度作用于整个窗口，包括网页、标签栏、地址栏；同一窗口内的所有标签页一起生效。
- 数值越小，窗口越透明；100% 表示完全不透明。
- 每个窗口分别调节，切换选择不会将上一个窗口的数值应用到下一个窗口。
- 正常关闭本程序会自动恢复原来的透明度。任务管理器强制结束、断电等不会执行正常退出恢复；这时关闭受影响的 Edge 窗口后重新打开即可。
- 不修改 Edge 配置，不安装浏览器扩展，不设置开机启动，不上传数据。
- 不能跨权限调整：如果 Edge 以管理员权限运行，请先正常重开 Edge，或让本程序以相同权限运行。
- 同时只运行一个控制面板，重复启动会激活已有窗口。

运行环境
Windows 10 2004（19041）及以上，Windows 11，x64。
发布目录包含 .NET 与 Windows App SDK 运行依赖，无需另装开发环境。
请保留整个文件夹，不能只移动其中的 EXE。

源码与重新构建
源码使用 C#、WinUI 3、.NET 10、Windows App SDK 2.5.1。
运行 publish.ps1 可重新生成 dist\EdgeOpacity-win-x64。
功能检查：dotnet run --project checks\OpacityChecks.csproj -c Release
